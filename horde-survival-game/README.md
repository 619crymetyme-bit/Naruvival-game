# Horde Survival - Stick Fighter

A fast-paced browser survival game inspired by games like Survivor.io and Naruto. Fight off waves of enemies, level up your character, and see how long you can survive!

## How to Play

- Use **WASD** or **Arrow Keys** to move your character
- Aim with your mouse and **click** or hold **Space Bar** to shoot
- Survive as many waves as possible
- Collect experience to level up and increase your stats
- Game ends when your health reaches zero

## Features

- Wave-based enemy spawning with increasing difficulty
- Projectile-based combat system
- Character leveling and stat progression
- Health and experience tracking
- Responsive design that works on desktop and mobile browsers
- Simple stick-figure graphics for fast loading

## Technical Details

- Built with vanilla HTML5, CSS3, and JavaScript
- Uses Canvas API for rendering
- No external dependencies
- Single file implementation for easy distribution
- Mobile touch support (aim by touching screen)

## Launch Instructions

1. Simply open `index.html` in any modern web browser
2. Or host it on any static web server (GitHub Pages, Netlify, Vercel, etc.)
3. No build process or installation required

## Development

To modify the game:
1. Edit `index.html` directly
2. Adjust game constants in the JavaScript section for balancing
3. Modify colors, sizes, and values in the CSS section

## Gameplay Tips

- Keep moving to avoid getting surrounded
- Focus fire on stronger enemies first
- Use the edges of the screen to funnel enemies
- Level up quickly to increase your fire rate and health
